# Pikbo 首页：内容优先的潮玩视频入口

**状态：** V1 实现，待评审  
**产品原则：** 先把首页做成让人愿意看潮玩视频的地方，再把生成功能嵌进去。

## 目标

首页不是 AI 工具说明书，而是潮玩视频内容站：

1. 第一眼被真实、清晰的潮玩视频抓住。
2. 愿意继续浏览、筛选和放大观看。
3. 看视频时随时能选择“生成同款”。
4. 浏览之后自然进入真实上传生成流程。

学习 Higgsfield 的是内容密度、观看动线和自然转化，不复制其文案、品牌或通用 AI 套件结构。

## 固定信息架构

1. **视频首屏**
   - 大面积官方 Lab 视频。
   - 一句主标题：让你的潮玩动起来。
   - 一句副标题。
   - 主 CTA：用我的潮玩生成。
   - 次 CTA：先看看示例。
2. **潮玩视频墙**
   - 全部 / 360° / 开箱 / 漂浮 / 收藏展示 / Listing。
   - 首排四张 Premiere 大卡，随后进入密集内容墙。
   - 进入视口后静音循环，受全局播放预算约束。
   - 点击卡片在站内放大观看，不把用户立即带离内容流。
   - 放大层与每张卡片都有“生成同款”。
3. **真实生成入口**
   - 墙后直接上传用户拥有的潮玩照片。
   - 保留 Free Mini、时长、清晰度和水印的真实说明。
4. **三点价值**
   - 保留潮玩细节。
   - 一张照片多种输出。
   - 可分享，也可用于 Listing。
5. **底部回流**
   - 上传照片生成。
   - 回视频墙继续浏览。

## 视觉约束

- 近黑底色可以保留，但首页允许粉、紫、橙的局部潮流光晕。
- 视频始终是视觉主体，文字不能盖过内容。
- 潮玩封面必须来自官方 Lab / 已登记项目，不伪装成用户 UGC。
- 不用大段功能罗列占据主路径。SEO 正文保留在折叠说明中。

## 交互与性能

- 视频静音、循环、`playsInline`。
- 首屏主视频优先；视频墙媒体进入视口后才加载。
- 视频墙最多同时播放 4 条桌面 / 2 条移动端预览。
- 离开浏览器标签页时暂停所有已认领预览。
- 放大层支持关闭按钮、点击背景关闭、Escape 关闭，并锁住背景滚动。
- 浏览视频墙时显示悬浮生成入口，到真实生成区自动隐藏。
- `prefers-reduced-motion` 用户不自动轮播或播放。

## 事件与验收

- 打开放大视频：`project_open`，`source=toy_wall_watch` 或
  `toy_wall_featured_watch`。
- 从卡片或放大层生成：`recipe_use`，区分 `toy_wall_remake` /
  `toy_wall_featured_remake` / `toy_wall_lightbox`。
- 上传及生成继续沿用 `upload_ready` → `generate_start` →
  `generate_result`。

验收必须通过 TypeScript、目标 ESLint、`engine-smoke` 和生产构建。
