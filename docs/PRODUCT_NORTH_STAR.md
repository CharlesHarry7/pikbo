# 产品北极星 — 潮玩版 Higgsfield

**老板定调（2026-07-25）：**  
> 我就是要做潮玩版的 https://higgsfield.ai/

这不是「冲动」，这是 **产品是什么**。  
哥飞管的是 **怎么冷启动活下来**，不是否定这个产品形态。

---

## 1. 两句话分清

| 层级 | 内容 | 权威 |
|------|------|------|
| **产品北极星** | 潮玩 / 设计师玩具垂直的 **AI 视频创作 OS**（HF 的信息架构 + 密度 + Generate 中心，全部换成玩具场景） | **老板** |
| **增长节奏** | 公网 soft → GSC/外链 → 有搜索信号再变现；不假 UGC、不假多模型 | **哥飞** |

冲突时的解法：

- **不做什么：** 不为了 SEO 把产品改成「只有长文工具站、没有 suite」  
- **不做什么：** 不为了像 HF 而停掉外链、开假功能、未稳就 Stripe  
- **做什么：** **HF 壳持续补齐（产品）** + **哥飞外链/收录（增长）并行**，按周交付可感知的 HF 模块，且不破坏已上线的关键词页与 GSC

---

## 2. 「潮玩版 HF」定义（验收体感）

打开 pikbo.ai 应感觉：

1. **进站是视频 OS**，不是 Brochures 博客  
2. **Generate 是中心动作**（底栏 / 顶栏 / 页内工具）  
3. **墙 / Flow / Modules / Library / Community** 路径同构 HF  
4. 内容全是 **玩具、手办、盲盒、listing、drop** —— 不是通用人脸玩法  
5. 诚实：Lab demo 标注、Soon 模型不写 live、无假热度

合法：抄 IA / 布局 / 密度 / 工作流；**不抄** HF 片源、商标、文案、用户内容。

---

## 3. 现状 vs HF（诚实）

| HF 模块 | Pikbo | 差距 |
|---------|--------|------|
| Explore 视频墙 | 有（Lab） | 密度/动效可再压；UGC 真帖未起量 |
| 产品入口轨 | 有 | 可更「战役化」 |
| Generate 工作台 | 有 | 细节/模型条/结果台继续打磨 |
| Flow / Modules | 有 | 密度与动线 |
| Library | 本地为主 | 云端/多设备 |
| Community | Lab + UGC 管线预埋 | 真用户内容 |
| 多模型 | Soon | **永不假 live** |
| 付费 | 关 | 有搜索信号再开（哥飞） |
| SEO 关键词页 | 有 | 增长用，不替代 suite |

**已是「HF 骨架的玩具站」约 50–60% 壳；不是 0。**  
差的是内容密度、真社区、云同步、付费、模型广度——这些用时间堆，不是一晚上。

---

## 4. 双轨排期（执行用）

### 轨 A — 增长（哥飞，不砍）

- 免费目录 ≤20/周  
- GSC 观察  
- 主词页 `/tools/ai-toy-video-generator` 保持 On Page  
- **不**为对标毁掉关键词页与页内工具  

### 轨 B — 产品（潮玩 HF，老板北极星）

每周至少交付 **1 个可感知的 HF 同构模块**（在红线内）：

| 周序（示例） | 模块 | 说明 |
|--------------|------|------|
| 持续 | Generate 手感 | 结果台、等待、失败恢复、移动端 |
| W1–2 | 墙 + Explore 密度 | 更多 Lab 证明、hover/分类、像 HF 墙 |
| W2–3 | Library 云感 | 登录后列表；无 Supabase 仍诚实 Local |
| W3–4 | Community 真帖 | SQL 已有；登录发布；无帖只显示 Lab |
| 之后 | Cinema / 战役条 / Seller Pack | 加深，不假模型 |
| 有流量后 | Stripe | 哥飞信号到了再开 |
| 有 key 后 | 第二模型 | 真 key 才 live |

### 红线（两边都遵守）

- 不假 UGC、不假 Kling/Veo live  
- 不抄 HF 资产  
- 收费前 T6 可并行预研，不阻塞 HF 壳  
- 主词页与 GSC 不回退
