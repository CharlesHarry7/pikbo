**老板定调（2026-07-25，再次确认）：**  
> 我就是要做潮玩版的 https://higgsfield.ai/

这是 **产品是什么**，不是口号、不是「以后再说」。  
工程默认优先：**把 Pikbo 做成潮玩垂直的 AI 视频创作 OS**。

哥飞只管 **怎么冷启动活下来**（外链 / GSC / 关键词页），**不能**把产品改写成「只有 SEO 工具站」。

## 1. 权威顺序（写死）

| 优先级 | 层级 | 内容 | 权威 |
|--------|------|------|------|
| **P0** | **产品北极星** | 潮玩版 HF：IA + 密度 + Generate 中心 + 墙/Flow/Library/Community，内容全是玩具场景 | **老板** |
| P1 | 增长节奏 | soft live → 免费外链 → GSC 信号 → 再 Stripe；不假 UGC、不假多模型 | **哥飞** |

冲突时：

- **砍掉：** 用长文博客替代 suite、为 SEO 拆掉 Generate 中心感  
- **砍掉：** 假 UGC、假多模型 live、抄 HF 片源/商标  
- **保留：** 页内工具 + 关键词页（养站），**同时**每周硬补 HF 模块  
- **工程时间：** 默认 ≥60% 花在 HF 同构体感，≤40% 增长/运维，不是反过来

## 2. 「潮玩版 HF」验收体感

打开 [pikbo.ai](https://pikbo.ai) 应感觉：

1. **进站是视频 OS**，不是 brochure  
2. **Generate 是中心**（底栏中键 / 顶栏 / 页内工具）  
3. **墙 / Flow / Modules / Library / Community** 路径同构 HF  
4. 内容全是 **玩具、手办、盲盒、listing、drop**  
5. 诚实：Lab 标注、Soon 不写 live、无假热度  

合法：抄 **IA / 布局 / 密度 / 工作流**。  
非法：抄 **HF 片源、商标、文案、用户内容**。
